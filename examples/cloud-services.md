# Примеры облачных сервисов

## IaaS
- Amazon EC2
- Microsoft Azure Virtual Machines
- Google Compute Engine

## PaaS
- Google App Engine
- Azure App Service
- Heroku

## SaaS
- Google Workspace
- Microsoft 365
- Salesforce

## Вывод
IaaS предоставляет пользователю наибольший контроль над инфраструктурой, PaaS упрощает разработку и запуск приложений, а SaaS предоставляет готовые программные продукты через интернет.
