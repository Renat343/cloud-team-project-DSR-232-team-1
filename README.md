# Каталог облачных сервисов

Учебный проект команды ДСР-232 по дисциплине «Основы облачных технологий».
**Назначение проекта** — помочь студенту сравнить модели IaaS, PaaS и SaaS,
найти примеры сервисов и освоить совместную работу с документацией в GitHub.

Каталог реализован как набор Markdown-документов, размещённых в GitHub.
Работа с ним начинается с этого README: далее можно перейти к
[описанию моделей](docs/iaas-paas-saas.md) и [примерам сервисов](examples/cloud-services.md).

## Архитектура

| Компонент | Назначение | Взаимодействие |
| --- | --- | --- |
| Клиент — браузер пользователя | Показывает каталог и позволяет переходить по ссылкам | Отправляет HTTPS-запросы к GitHub и отображает полученные страницы |
| Облачная платформа GitHub | Хранит репозиторий, отображает Markdown, предоставляет Issues и Pull Requests | Получает запросы браузера, читает файлы выбранной ветви и формирует страницы |
| Данные каталога — Markdown-файлы | Содержат описания моделей и примеры сервисов | GitHub отображает их содержимое, а участники обновляют файлы через Git и Pull Request |
| Локальная копия и Git | Позволяют редактировать документацию и сохранять историю изменений | Git получает файлы из GitHub и отправляет commits в отдельную ветвь |

Схема чтения каталога:

```text
Пользователь → браузер → GitHub → Markdown-файлы выбранной ветви
Пользователь ← браузер ← отображённая страница каталога
```

Схема обновления:

```text
Участник → локальная копия → commit → отдельная ветвь на GitHub
         → Pull Request → проверка → объединение в main
```

Прототип использует GitHub как облачную платформу совместной работы.
Собственного веб-сервера, базы данных и исполняемого приложения в проекте нет.
Документы являются хранилищем данных каталога.

### Категории и структура данных

| Категория | Что предоставляется | Примеры из каталога |
| --- | --- | --- |
| IaaS — инфраструктура как услуга | Вычислительные ресурсы, сеть и хранилище | Amazon EC2, Microsoft Azure Virtual Machines, Google Compute Engine |
| PaaS — платформа как услуга | Среда для размещения и выполнения приложений | Google App Engine, Azure App Service, Heroku |
| SaaS — программное обеспечение как услуга | Готовое приложение через интернет | Google Workspace, Microsoft 365, Salesforce |

В `docs/iaas-paas-saas.md` данные представлены сравнительной таблицей
с полями «Модель», «Полное название», «Что получает пользователь»,
«За что отвечает пользователь», а также поясняющими разделами.
В `examples/cloud-services.md` каждой категории соответствует заголовок
второго уровня и список названий сервисов. Отдельной записи с идентификатором,
ценой или API-адресом в текущем формате нет.

## Запуск учебного прототипа

### Просмотр через GitHub

**Предварительные условия:** браузер и доступ к интернету.
Для чтения публичного репозитория регистрация не требуется.

1. Откройте [репозиторий проекта](https://github.com/Renat343/cloud-team-project-DSR-232-team-1).
2. Выберите ветвь `docs/lab4-markdown`, чтобы просмотреть документацию лабораторной №4.
   После объединения Pull Request используйте `main`.
3. Прочитайте README, затем откройте [описание IaaS, PaaS и SaaS](docs/iaas-paas-saas.md).
4. Перейдите к [примерам облачных сервисов](examples/cloud-services.md) и сравните категории.

Ожидаемый результат: GitHub показывает заголовки, таблицы, списки и рабочие ссылки.
Это и есть запуск доступного документного прототипа; отдельный сервер запускать не нужно.

### Получение и просмотр локальной копии

**Предварительные условия:** установленный Git, терминал, доступ к интернету
для клонирования и текстовый редактор с предпросмотром Markdown.
Проверьте наличие Git командой `git --version`.

1. Клонируйте репозиторий и перейдите в его каталог:

   ```bash
   git clone https://github.com/Renat343/cloud-team-project-DSR-232-team-1.git
   cd cloud-team-project-DSR-232-team-1
   ```

2. Переключитесь на ветвь лабораторной №4:

   ```bash
   git switch docs/lab4-markdown
   ```

   После объединения изменений можно использовать `git switch main` и `git pull`.

3. Откройте `README.md` в редакторе и включите предпросмотр Markdown.
4. Откройте `docs/iaas-paas-saas.md` и `examples/cloud-services.md`.
   Убедитесь, что видны три категории и примеры сервисов.

После клонирования текстовые материалы доступны без интернета.
Установка программных зависимостей, Python или Docker для этого прототипа не требуется.

## Используемые технологии

| Технология | Применение в проекте |
| --- | --- |
| Git | Версии файлов, commits, ветви и синхронизация локальной копии |
| GitHub | Облачное хранение репозитория, отображение документации, Issues и Pull Requests |
| Markdown | Заголовки, списки, таблицы, ссылки и фрагменты команд |
| Браузер и HTTPS | Доступ к страницам каталога в GitHub |

Названия облачных сервисов в каталоге являются учебными примерами.
Проект не подключается к их API и не требует аккаунтов этих провайдеров.

## Ограничения и безопасность

- Каталог содержит учебные описания и примеры, а не актуальные тарифы или рекомендации по закупке.
- Поиск, авторизация пользователей и автоматическое обновление данных не реализованы.
- Публичные материалы доступны читателям; изменение репозитория требует соответствующих прав.
- **Пароли, токены и ключи доступа нельзя добавлять в файлы и историю Git.**
  Для текущего прототипа секреты вообще не нужны.
