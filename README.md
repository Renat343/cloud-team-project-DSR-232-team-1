# Каталог облачных сервисов

Учебный мини-проект по дисциплине «Основы облачных технологий».

## Цель проекта

Подготовить небольшой каталог облачных сервисов и показать командную работу в GitHub:
Issues, отдельные ветви, commits, Pull Requests, review и merge.
